THE OPERATOR’S NOTES

A circuit that never
stands still.

01. Set the daily key

Choose the rotor order, ring settings, reflector, starting windows, and plugboard pairs. Both operators need exactly the same settings.

02. Press and hold a letter

The wheels step before the current passes through the plugboard, rotors, and reflector, then returns to light one lamp. Release the key to extinguish it. The original machine did not print; the transcript here records the lamps for you.

03. Reset to read the reply

Return to the original starting windows, then type the ciphertext. The same circuit recovers the plaintext. There is no separate decrypt mode.

Service machines used three rotors, or four in the naval M4. The M4’s leftmost Beta or Gamma wheel stays stationary. Custom stacks extend the pawl stepping rules to any positive rotor count; repeated types and other combinations are experimental.
